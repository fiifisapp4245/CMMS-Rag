# CMMS Assistant demo

A clickable demo of a maintenance log assistant: ask a question, watch the stages, and check each sentence against its source records.

Every record and answer is invented and canned. The demo calls no model and holds no real maintenance data. Past questions stay in each viewer's browser, and feedback goes to the deployment's runtime logs.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this repository and keep the detected Next.js settings. No environment variables are needed.
